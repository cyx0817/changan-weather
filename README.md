# 长安有雨

从西安开始的非商业天气网页：最大可见跨度 100 米的动漫风 3D 近景、当前天气、24小时和七日预报、雨雪氛围、可互动小猫“小满”、系统语音和本机录音提醒。

发布：在本仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 /(root)，保存。无需构建或 API 密钥。

原声提醒录音仅存于访客浏览器。可选的 MiniMax AI 音色需要单独部署私人后台、配置账号并由用户同意上传；云端功能尚未开通时界面会明确显示待开通，不会伪装为克隆成功。后台见仓库 changan-weather-backend.zip（解压后）（运行在 Cloudflare Worker，不在 Pages 中执行）。访问口令不持久保存；MiniMax 密钥只放后台。

未获取定位时，默认显示钟楼附近示例。点击“定位到我身边”后围绕实际位置更新近景，定位精度取决于设备。去除圆形边界和遮罩，街景铺满地图区域；按可见地面经纬度范围动态限制镜头，横纵跨度均不超过 100 米。使用 ＋／− 查看细节，↻ 旋转，2D／3D 切换视角；固定所选位置，避免拖动或手势缩放将视图带离近景。建筑轮廓受地图瓦片精度限制。建筑位置保留真实轮廓，屋顶、窗户、颜色和高度为艺术化表现，天气来自模型数据，雨雪动画不代表逐栋建筑实测。

数据署名：Open-Meteo (CC BY 4.0)、OpenFreeMap / OpenMapTiles / OpenStreetMap。地图渲染使用 MapLibre GL JS 5.6.2，其许可证见 LICENSE.txt。

地图与天气需要联网，具体网络的可用性以实际访问为准。系统播报和录音取决于浏览器支持与用户权限。

落花氛围：默认开启轻柔花瓣，与实时天气／雨雪演示独立；点击“✿ 落花”可关闭。尊重系统减少动态效果偏好，轻量模式下花瓣静止。粉白花树、花枝及散落花瓣为艺术化装饰，不代表当地花期。

打开链接会请求设备定位授权；允许后自动切换当前位置的天气与街景。拒绝、超时或不支持定位时明确显示原示例地点，可点击定位按钮重试。坐标仅在内存中使用，不保存位置历史；实际精度由设备决定。
